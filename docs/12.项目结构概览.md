# 项目结构概览

> 1-10 步完成后的完整项目结构。核心是**四层架构**：框架层（core）→ 业务层（apis/schemas）→ 用例层（tests）。

## 四层架构

```text
core/      框架核心层：配置/日志/HTTP/断言/加密/数据生成（通用能力，不涉及具体业务）
apis/      接口封装层：按业务模块封装后端接口（BaseApi 基类 + 各模块）
schemas/   数据模型层：pydantic 响应模型（响应结构校验）
tests/     测试用例层：unit / contract / integration 三层
```

## 完整目录树


## 哪些不进 git（.gitignore 已挡）

```text
.venv/          虚拟环境（uv sync 重建）
.env.test       真实凭据（只提交 .env.example 模板）
data/login_cases.yaml   测试数据（只提交 *.example 模板）
reports/        报告产物
logs/           运行日志
.dsh/           DSH 会话产物
.history/       IDE 历史
__pycache__/    字节码缓存
.coverage       覆盖率数据
```
