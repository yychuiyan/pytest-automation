# Jenkins 运行配置（Docker 方案）

标准 Docker + Jenkins 部署方式。

## 一、构建并推送测试镜像

```bash
# 在项目根目录执行（需先 commit uv.lock）
docker build -t pytest-automation/runner:v1.0.0 .
docker tag pytest-automation/runner:v1.0.0 172.22.12.114:5000/pytest-automation/runner:v1.0.0
docker push 172.22.12.114:5000/pytest-automation/runner:v1.0.0
```

镜像内已预装 Python 3.11 + 全部依赖到 `/app/.venv`，业务代码由 Jenkins `checkout scm` 拉取。

## 二、Jenkins 前置配置

| 项 | 说明 |
| --- | --- |
| 插件 | Docker Pipeline Plugin、Allure Jenkins Plugin |
| 凭据 | `api-auto-env`（Secret file，上传本地 `.env` 文件） |

## 三、新建流水线

1. New Item → Pipeline → 配置 Pipeline script from SCM（Git）
2. 指定仓库地址与分支
3. Script Path 填 `Jenkinsfile`

## 四、构建参数

`TEST_SUITE` 选择测试套件：

| 值 | 说明 | pytest 命令 |
| --- | --- | --- |
| smoke | 冒烟 | `-m smoke` |
| regression | 冒烟+回归 | `-m "smoke or regression"` |
| all | 全量 | `pytest`（无筛选） |

## 五、报告

- **Allure**：由 Allure Jenkins Plugin 在 `Publish Allure Report` 阶段发布
- **JUnit**：`reports/junit.xml` 进入 Jenkins 测试趋势图
- **HTML**：`reports/pytest-html/` 归档为构建产物

## 六、本地开发

```bash
uv sync          # 首次同步依赖
cp .env.example .env  # 配置环境变量
make smoke       # 冒烟测试
make report      # 本地生成 Allure 报告（需先 brew install allure）
```
